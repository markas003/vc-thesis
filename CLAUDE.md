## Working rules

- Write in English, cite in APA 7.
- Stay source-grounded: cite only papers in these folders. Never invent references, findings or page numbers. If something is not in the sources, say so and ask.
- Follow the RSM thesis manual for structure and formal requirements. Read the PDF when a formatting or requirement question comes up.
- Do not modify existing literature files or the old proposal. Write new drafts as new files, for example in `2 Final Thesis Proposal/`.
- Literature summaries cover: research question, theory, sample/data, method, key findings, limitations, and relevance to cross-border VC in Europe and to candidate moderators.
- Data analysis (later): keep raw data untouched, keep scripts reproducible, state assumptions and variable definitions. Ask which tool (Python, R or Stata) before starting.
- Feedback and planning: check drafts against the manual and supervisor comments.
